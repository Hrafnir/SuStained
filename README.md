# Sustained / SuStained

**[Spill Tier I-prototypen](https://hrafnir.github.io/SuStained/)** · [Kildekode](https://github.com/Hrafnir/SuStained)

Første spillbare versjon: 2–5 spillere på delt skjerm, 8 runder og 15 teknologier fordelt på industri, transport og mat. Inkluderer landbrett, produksjon, forskning, bygging, handel, mating, vekst, poeng, lagring og angre. Se [utviklingsinstruksjoner](game/README.md).

Tier II, Tier III og samarbeidsfasen er fortsatt planlagt. Den digitale versjonen er en prototype med foreløpige balanseverdier.

Brettspillprosjekt overtatt fra en delt ChatGPT-samtale 7. september 2026.

- [Prosjektstatus og beslutninger](PROSJEKTSTATUS.md)
- [Gjennomføringsplan for digitalt brettspill](GJENNOMFORINGSPLAN.md)
- [Tier 1: eksisterende kortgrunnlag](design/tier-1.md)

Kilde: https://chatgpt.com/share/6a9ed192-e854-83ed-b9dc-72797e74aae6

Dette er en strukturert overføring av lest samtaleinnhold, ikke en komplett eksport av samtalen eller bildefilene. Mappen var tom ved overtakelsen. Kortreglene er prototyper og er ikke spilltestet her.

Arbeidsform: Eirik styrer innhold og designbeslutninger. Assistenten er sparringspartner, vurderer ideer og kommer med forslag. Nye spillkomponenter produseres på konkret bestilling.
